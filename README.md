## What It Does

Grid the Grey monitors 37 curated RSS feeds across AI vendors, security research, and tech news. Each article is first classified by Claude Haiku (low-cost pre-filter) then fully scored by Claude Sonnet for relevance to AI/ML security (threshold 6.0/10) and mapped to MITRE ATLAS techniques and OWASP LLM Top 10 categories.

The platform delivers intelligence through three channels:
- **Website** — Hugo static site with threat radar, framework badges, and live ticker
- **Newsletter** — Twice-weekly HTML digest (Tuesday + Friday, 9:30 AM IST) via Resend
- **Podcast** — Weekly CISO audio briefing (Monday, 10:00 AM IST) via OpenAI TTS

All pipelines run automatically via GitHub Actions.

## GitHub Actions Workflows

### deploy.yml — Build & Deploy
**Trigger:** Push to `main` (paths: `hugo-site/**`)

1. Auto-publishes any drafts with `draft: false` (moves from `drafts/` to `posts/`)
2. Builds Hugo site (minified)
3. Deploys to GitHub Pages
4. Notifies Google Indexing API for faster crawling

### pipeline.yml — RSS Ingestion
**Trigger:** Manual dispatch only

Fetches 37 RSS feeds, applies keyword pre-filter (200+ terms, no API cost), classifies with Claude Haiku, scores with Claude Sonnet, maps MITRE ATLAS + OWASP LLM, writes drafts. First Look and threat articles are interleaved 1:1 to maintain ~50/50 balance. Commits results back to repo.

**Inputs:** `limit`, `dry_run`, `reprocess`, `feed` (single feed selection)

### newsletter.yml — Email Digest
**Trigger:** Cron — Tuesday & Friday at 04:00 UTC (9:30 AM IST)

Generates dark-themed HTML digest (lead story + 7 secondary), fetches subscribers from Mailerlite, sends via Resend batch API.

**Inputs:** `days` (lookback), `dry_run`, `subject` (custom)

### ciso-briefing.yml — Podcast
**Trigger:** Cron — Monday at 04:30 UTC (10:00 AM IST)

Generates script (Claude) → produces MP3 (OpenAI TTS) → uploads to R2 → updates podcast feed → commits episode metadata.

**Inputs:** `voice` (onyx/echo/nova/alloy/fable/shimmer), `days`, `dry_run`

### draft-cleanup.yml — Expire Old Drafts
**Trigger:** Cron — Daily at 00:30 UTC; also manual dispatch

Deletes drafts older than 15 days (configurable). Prevents stale content accumulation.

### publish-draft.yml — Manual Publishing
**Trigger:** Manual dispatch

Lists available drafts or publishes a specific slug. Runs duplicate detection before publishing.

## Setup from Scratch

### Prerequisites

- Python 3.12+
- Git
- A GitHub account
- An Anthropic API key (get one at console.anthropic.com)
- Hugo extended 0.140.2+ (for local preview only)

### Step 1: Clone and configure

```bash
git clone https://github.com/bansac1981/sentinel-ai.git
cd sentinel-ai

pip install -r requirements.txt

cp .env.example .env
```

Edit `.env` and add your keys:
```
ANTHROPIC_API_KEY=sk-ant-...
CLAUDE_MODEL=claude-sonnet-4-6
UNSPLASH_ACCESS_KEY=...
PEXELS_API_KEY=...
RESEND_API_KEY=re_...
MAILERLITE_API_KEY=...
MAILERLITE_LIST_ID=...
OPENAI_API_KEY=sk-...
R2_ACCOUNT_ID=...
R2_ACCESS_KEY_ID=...
R2_SECRET_ACCESS_KEY=...
R2_BUCKET_NAME=...
R2_PUBLIC_URL=...
```

### Step 2: Dry run

```bash
python pipeline.py --dry-run
```

### Step 3: Run the pipeline

```bash
python pipeline.py --limit 3
```

New `.md` files will appear in `hugo-site/content/posts/drafts/` with `draft: true`.

### Step 4: Preview locally

```bash
cd hugo-site
hugo server -D   # -D shows drafts
# Open http://localhost:1313/
```

### Step 5: Push to deploy

```bash
git add .
git commit -m "publish: [article title]"
git push
```

GitHub Actions builds and deploys automatically (~2 minutes).

## Newsletter

### How it works
1. `newsletter_digest.py` reads published posts from the last 4 days
2. Ranks by `relevance_score`, picks top 8
3. Generates dark-themed HTML email (lead story with thumbnail + 7 secondary)
4. Fetches active subscribers from Mailerlite API (paginated)
5. Sends via Resend batch API (100 emails/batch, retry logic)

### Manual generation
```bash
python newsletter_digest.py --days 7 --output digest.html
python newsletter_digest.py --send --days 4
python newsletter_digest.py --send --dry-run
```

### Subscriber sign-up
Embedded Mailerlite form on every article page, header, and footer. Welcome email triggered automatically by Mailerlite automation.

## Podcast (CISO Audio Briefing)

### How it works
1. `weekly_briefing.py --generate` reads the week's posts, calls Claude to write a ~450-word CISO-level script
2. `weekly_briefing.py --produce --voice onyx` converts to MP3 via OpenAI TTS (tts-1-hd)
3. Uploads MP3 to Cloudflare R2
4. `podcast_feed.py --update` regenerates iTunes-compatible RSS feed on R2
5. Episode metadata saved to `briefings/episodes.json`

### Available voices
onyx (default, authoritative), echo, nova, alloy, fable, shimmer

### Manual commands
```bash
python weekly_briefing.py --generate --days 7
python weekly_briefing.py --produce --voice onyx
python weekly_briefing.py --list
python podcast_feed.py --update
```

## Troubleshooting

**Pipeline fails with `ANTHROPIC_API_KEY not set`**  
Add the secret at: repo Settings → Secrets and variables → Actions → New repository secret.

**Hugo build error: `theme not found`**  
Make sure there is no `theme = "..."` line in `hugo.toml`. The site uses custom layouts only.

**Links go to wrong path**  
Hugo's `relURL` breaks with leading-slash inputs. Use `{{ "posts/" | relURL }}` (no leading slash) or `{{ .Site.Home.RelPermalink }}`. The baseURL must be hardcoded in both `hugo.toml` and `deploy.yml`.

**`seen_urls.json` is growing large**  
Expected — stores all seen article URLs for deduplication. Committed to repo so Actions maintains state between runs. Can be safely trimmed.

**Posts not appearing on site**  
Check that `draft: false` is set and the file is in `posts/` (not `posts/drafts/`). Use the `publish-draft.yml` workflow or set draft to false and push.

**Newsletter not sending**  
Verify `RESEND_API_KEY`, `MAILERLITE_API_KEY`, and `MAILERLITE_LIST_ID` secrets are set. Run with `--dry-run` first to validate content generation.

**Podcast audio not generating**  
Check `OPENAI_API_KEY` secret. Verify R2 credentials are valid. Run `weekly_briefing.py --generate` first to confirm script generation works.
