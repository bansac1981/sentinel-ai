This week's Grid-the-Grey CISO AI Security Brief — the AI development stack is now an active attack surface, and threat actors are moving faster than your patch cycles.

Start with the infrastructure. Langflow, the open-source AI app builder running in roughly a quarter of enterprise AI pipelines, has a critical unauthenticated remote code execution flaw — CVE-2026-5027 — with no patch. Auto-login is on by default, meaning a single HTTP request is all an attacker needs. No credentials. No sophistication. If Langflow is running in your environment, assume it is reachable and treat it as compromised until you can isolate it. LangGraph compounds this: Check Point disclosed a three-vulnerability chain in its persistence layer where SQL injection plus unsafe deserialization achieves full RCE. Fifty million monthly downloads. These are not niche tools — they are the scaffolding of enterprise agentic AI.

The agent exploitation story goes further. Tenet Security's Agentjacking research demonstrates an 85% success rate hijacking AI coding agents through the Model Context Protocol. Attackers inject malicious instructions into Sentry error events — data sources your agents treat as trusted — and those agents execute arbitrary code with full developer privileges. Claude Code and Cursor are both confirmed affected. This is OWASP LLM01 prompt injection at scale, but the attack surface is your observability tooling, not your LLM. Microsoft's own disclosure of the Claude Code GitHub Action vulnerability reinforces this: prompt injection through issue bodies and PR comments caused the agent to read CI/CD secrets directly from the process environment. Your pipeline is the threat surface.

On the offensive capability side, the Claude Mythos finding is a strategic signal. A frontier model compressed the patch gap for known Firefox and Windows vulnerabilities from weeks to hours. Simultaneously, University of Toronto researchers demonstrated an AI worm achieving 62% network penetration across a 33-host testbed with no human intervention, generating novel exploits at runtime. The era of fixed-payload malware is ending. Defenses built around signature detection are structurally unprepared for runtime-generated exploit chains.

The pattern this week is architectural. AI agents are trusted by design — by your pipelines, your registries, your observability tools. Attackers are exploiting that trust systematically, from the supply chain inward, and AI is now accelerating the offensive side of that equation faster than defenders can respond.

Three actions this week. First, inventory every Langflow and LangGraph deployment and network-isolate them now — no patch exists, containment is your only option. Second, audit your MCP-connected data sources and revoke any Sentry DSN credentials that are externally accessible. Third, brief your development security leads on the Claude Code GitHub Action disclosure and enforce untrusted-content sandboxing across all AI coding agent integrations in your CI/CD pipelines.
