This week's Grid-the-Grey CISO AI Security Brief — the AI development stack itself has become the attack surface, and exploitation is no longer theoretical.

Start with your agentic infrastructure. Langflow, the popular open-source AI app builder, has a critical unpatched remote code execution vulnerability — CVE-2026-5027 — being actively exploited right now. No credentials required. Auto-login is on by default, and a single HTTP request is enough. If your teams are running Langflow, treat it as compromised until a patch lands. This maps directly to OWASP LLM05 and MITRE's ML Supply Chain Compromise. It's not isolated. LangGraph's persistence layer has three chained vulnerabilities — SQLi to deserialization to full RCE — with fifty million monthly downloads in the blast radius. These aren't edge tools. They're in production pipelines everywhere.

The threat to AI coding agents is equally urgent. Tenet Security's Agentjacking research achieved an 85% success rate hijacking Claude Code and Cursor through poisoned Sentry error events. Attackers write malicious instructions into publicly accessible Sentry DSN-linked events, and the agent executes them with full developer privileges. That's OWASP LLM01 — prompt injection — weaponised at scale. Microsoft's disclosure compounds this: Claude Code's GitHub Action leaked CI/CD secrets, including API keys, through injected PR descriptions and issue bodies. Your agentic pipelines inherit the trust boundaries of every data source they read. Right now, most of those boundaries aren't enforced.

Supply chain integrity is collapsing in real time. The Miasma worm — attributed to TeamPCP — compromised 73 Microsoft-hosted packages. It activates specifically when developers open packages inside AI coding agents, and it bypasses SLSA provenance attestation. This is targeted sabotage of the developer workflow, not opportunistic malware. Pair that with Unit 42's Behavioral Integrity Verification findings — third-party AI agent skills routinely doing things completely different from what they advertise — and the trust model underlying the entire AI skills ecosystem is broken.

The pattern this week is structural. Attackers are targeting the seams — the orchestration layers, the plugin registries, the implicit trust between agents and their data sources. The AI stack was built for capability, not for adversarial conditions, and that gap is being exploited systematically.

Immediate priorities: audit every Langflow and LangGraph deployment and isolate them from production networks until patches are confirmed. Review all MCP and agent skill integrations using behavioral verification — assume descriptions lie. Enforce strict sandboxing on every AI coding agent in your CI/CD pipelines, treating all external data sources — issues, PRs, error logs — as untrusted input by default.
