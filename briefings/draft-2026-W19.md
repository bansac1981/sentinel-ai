This week's Grid-the-Grey CISO AI Security Brief — your AI infrastructure is now the primary attack surface, and this week proved that at scale.

Three converging supply chain stories demand immediate attention. First, a CVSS 10 vulnerability in Google's Gemini CLI allowed unauthenticated remote code execution by planting malicious config files in directories the agent trusted automatically in CI/CD mode. This isn't a theoretical prompt injection risk — it's a fully weaponised pipeline takeover, mapped directly to MITRE ATLAS ML Supply Chain Compromise and OWASP LLM's Supply Chain Vulnerabilities category. If you're running any agentic tooling in headless or automated pipeline modes, that trust model deserves scrutiny today.

Second, the LiteLLM gateway vulnerability, CVE-2026-42208, a pre-auth SQL injection scoring 9.3, was actively exploited within 36 hours of disclosure. Attackers showed prior knowledge of LiteLLM's internal schema, going straight for tables holding OpenAI, Anthropic, and AWS Bedrock credentials. This is credential harvesting at the AI infrastructure layer — and LiteLLM sits between your applications and your LLM providers in a lot of enterprise stacks. Credential theft here cascades across every model-dependent workflow you run.

Third, a backdoored PyTorch Lightning package on PyPI delivered a credential-stealing payload called ShaiWorm to AI developers, targeting cloud keys, GitHub tokens, and browser secrets. And separately, North Korean actors from Famous Chollima used Claude itself to help author malicious npm packages targeting crypto wallets — a nation-state actor weaponising frontier LLMs for supply chain infiltration. OWASP's Excessive Agency framing applies here: when an LLM agent can commit code or publish packages, its blast radius is your blast radius.

Underlying all of this is a structural shift. The AI toolchain — gateways, SDKs, CLI agents, developer frameworks — is now as contested as the application layer was in the mid-2010s. Attackers are moving faster than disclosure cycles, and they're using AI to do it. The UK AISI findings this week confirm frontier models can autonomously complete 32-step corporate intrusions. Offensive capability is no longer gated by nation-state resources.

Three actions for this week. Audit every CI/CD pipeline using agentic AI tooling — specifically which directories and config files those agents trust implicitly in headless mode, and patch Gemini CLI immediately. If LiteLLM is in your stack, rotate all upstream provider API keys now and treat any existing keys as compromised. Finally, mandate verified publisher checks and hash pinning for all AI and ML Python and npm packages — ShaiWorm and PromptMink both exploited the assumption that popular packages are safe packages.
